# 0.5.28 测试版（build 56）：读取 FLClash 当前链路

- 网络设置新增「读取 FLClash 当前链路」：定位当前配置的保存记录，登记拓展脚本处理后的生成配置，并自动预选 TCP 前置节点；支持多层手动 select。
- 修正多节点配置的错误提示。链式配置可以含多个前置候选；不再误导用户将机场订阅裁成单 HTTP 节点。
- 保存选择缺失、关系不符、读取或登记期间配置变化时明确拒绝应用；不默认挑选第一项。
- ISP 网关/端口与前置入口分离。域名前置仍需核对实际 Core 连接 IPv4，预期出口保持用户原值，端点仍需手动确认。

此功能不修改 FLClash 文件、不启动控制 API、不切换订阅或节点。保存记录仅为候选提示，现有实际连接、TUN、PF、负向探针和出口验证保持不变；不宣称逐请求证明内层链路。独立 UDP 防护及恢复逻辑不变。

使用：网络设置 → 读取 FLClash 当前链路 → 核对前置（域名时读取前置连接）→ 核对 ISP 与预期出口 → 确认端点 → 仅验证防护/安全启动 Claude。

提供 Apple Silicon、Intel DMG。测试版为临时签名，未获 Apple 公证；Intel 仅交叉构建及静态校验。自动化为离线逻辑与模拟恢复，真实网络验收由用户手动执行，开发期间不加载 PF 或切换代理。

更新按 DMG 说明先恢复并退出旧版、卸载，再安装新版；卸载清空设置，请提前记录必要信息。异常兜底：关闭防护 → 恢复工具选 2 → 仍断网选 3（全局 PF）→ 重启。保留反馈，不强删恢复资产。
