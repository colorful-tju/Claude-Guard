# 0.5.24 测试版：减少进程观测误停，改善恢复受阻

版本 0.5.24+51；macOS 14+，Apple Silicon / Intel。临时签名，未获 Apple 公证；Intel 未真机验收。

## 修复内容

- 修复无关进程身份暂时无法读取，持续 5 秒就关闭 Claude 的问题。已启动防护时，清单不完整改为持续告警和复核；PF、代理核心、TUN、路由、state、心跳及真实出口不匹配的处理保持不变。首次、持续异常和恢复均记录诊断，持续异常限频记录。
- 恢复受阻的三次主动尝试结束后，不再永久停止自动恢复。每 30 秒只读复核；完整清单确认无 Claude 后重新执行严格清理验收。仍无法确认时保持限制，不把未知进程当成已退出。
- 离线恢复模式 2 若因 Claude 退出无法确认而失败，可输入 `UNPROTECT_OWN` 明确解除本工具规则。仍要求助手停止、可信事务目录及锁、规则清理核验；不关闭全局 PF，不删除其他规则、state 或恢复记录。

## 使用与验证

1. 保存工作，先正常关闭防护再更新；旧事务无法恢复时，使用恢复工具，保留记录，必要时重启后再更新。
2. 手动准备代理/TUN，先“仅验证防护”，再“安全启动 Claude”。进行日常对话和工具调用，确认没有仅因无关 PID 不可读而自动关闭。
3. 点击“关闭防护”，确认 Claude 退出并回到 OFF；再启动一轮，从 Claude 菜单退出，检查恢复。
4. 若显示进程观测受限，核对反馈中的 `last-monitoring-degradation.json`。这表示观测不完整，不是泄漏结论。恢复受阻时等待下一轮低频复核，仍失败则导出反馈。

本版离线测试不等于实机验收；不保证所有 macOS 卡死进程可被自动结束。未知身份持续不可读时正常 OFF 仍可能受阻，用户可明确选择应急解除保护。既有同次开机助手崩溃的工作进程归属限制保持不变。

兜底：安装器或应用内“恢复工具” → `恢复网络.command` → 先选 2；仅进程退出确认受阻时按提示输入 `UNPROTECT_OWN`。这会解除本工具保护，不能继续使用 Claude 并假定受保护。仍断网再选 3（可能停用整个 PF，影响其他防火墙），按提示输入 `UNPROTECT`；仍失败保存工作后重启。恢复工具会将操作输出保存到桌面 `ClaudeGuard恢复-*`；请一并提供，不删除事务文件。
