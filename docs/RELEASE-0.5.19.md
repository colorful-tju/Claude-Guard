# 0.5.19 测试版：修复默认配置路径误读旧订阅

版本 0.5.19+46，macOS 14+；Apple Silicon / Intel。临时签名，未获 Apple 公证；Intel 未真机验收。

## 修复

此前默认安装固定登记 `~/Library/Application Support/com.follow.clash/config.yaml`。该文件可能是旧订阅，与 FLClash 当前界面节点不一致，导致反复显示笼统的 `ruby failed (1)`。

- 默认安装仅登记代理核心，配置需在 App「网络设置 → 选择并登记配置」中明确选择。页面展示当前登记路径。
- OFF 且本工具防护资产已清理时才能更改路径；候选验证失败保留旧登记；写入失败恢复并核验旧登记，恢复也失败则阻止继续启动并提示重装。复用已安装助手权限，不自动切换订阅、TUN、DNS 或启动 Claude。
- 登记发出即清空旧端点确认；回复丢失或 OFF 抢先完成也必须重新确认。
- 解析错误显示节点数量、协议/字段或 YAML 问题；反馈保留错误，避免再次依赖额外脚本。原始 YAML、密码和 Ruby stderr 不进入反馈。
- 安装时若显式选择配置，会在替换原组件之前检查格式与所有者；默认安装不伪称已完成配置验证。

配置登记仅提供候选依据，不证明核心加载了同一文件；安全启动仍核验 Core 身份、实际网关连接、TUN、PF、负向探针和预期出口。不会扫描目录自动挑一个能通过的 YAML；多节点/非 HTTP 等兼容性限制保持不变。

## 使用与验证

1. 先正常关闭防护并恢复退出，保存网络设置，按 DMG 说明移除旧版再安装。
2. 保持 OFF，在网络设置选择当前代理实际使用的单节点 HTTP YAML。不要选旧机场订阅，也不要为了过检查临时导出无关文件。原始配置与生成配置不一致时需核对实际节点；无法确认则不要安全启动。
3. 确认显示的路径、网关/端口正确，填写预期出口并确认端点。
4. 手动准备代理/TUN，先“仅验证防护”并关闭，再安全启动 Claude。
5. 如仍失败，导出反馈并附选择的文件类别、操作时间和提示；不要上传密码或完整私有 YAML。

本轮离线测试、安装模拟与打包验证不代替朋友电脑上的实际代理/PF 验收。

## 兜底恢复

安装器 → 恢复工具 → `恢复网络.command`，先选 **2**，仍断网选 **3**。核验受阻时阅读说明后输入 `UNPROTECT`；选项 3 可能停用整个 PF，影响其他防火墙。不要继续使用 Claude；仍断网则重启并保留输出。
