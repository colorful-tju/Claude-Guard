# 0.5.31 测试版：修复安装资源缺失

0.5.30 的 DMG 包含新版 ZIP，但安装脚本仍引用 0.5.29 文件名，导致安装提前返回“安装资源缺失”。该失败位于创建安装锁、停止助手和替换组件之前；单独此次报错不会改变原有防护或网络。

修复：
- 安装器内部统一使用固定名称 ClaudeSafeLauncher-test.zip，不再逐版修改其引用。
- 打包时和实际 DMG 验收时执行安装脚本的 --check-resources 只读路径，不授权管理员、不安装、不修改网络。
- 安装回归夹具只提供一个真实预期的包，删除过去同时放入所有历史版本 ZIP、掩盖错配的测试方式。

请重新下载 0.5.31 DMG，不再使用 0.5.30 安装器。退出失败的安装器后，确认防护已关闭、旧 App 已退出，按 DMG 内说明安装。无需因该错误运行全局 PF 恢复或重置代理。

应用防护和独立前置测试逻辑未改动；仍属待真实节点验收的预发布版。安装后按 0.5.30 测试说明验证前置连接，并反馈结果。若后续正式防护测试断网，使用包内恢复工具，优先正常恢复，模式 3 仅最后兜底。
