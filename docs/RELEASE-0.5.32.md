# 0.5.32 测试版：修复前置节点空值兼容

截图中的“未核验连接”说明已经读到候选；没有自动填入，是因为独立测试的参数解析阶段拒绝了 `flow: null`，尚未进行协议测试。并非检测到泄露，也不能据此判断这些候选均不可用。

此版本将 VLESS WebSocket 节点缺省、null、空字符串 flow 等同未设置处理，不向临时 Core 添加 flow。非空 flow、布尔、数字及集合仍拒绝。未放宽证书校验、接口绑定、候选核验或 PF 规则。失败提示改为固定的具体中文原因，不输出密码或 UUID。

已使用当前节点只读提取复现旧错误；修复后参数提取通过。合成回归覆盖 null、空字符串及非法类型。未启动真实 Core 测试，不修改 FLClash 配置、节点、TUN、DNS 或系统网络。

## 请这样复测

1. 关闭 Guard 防护并退出，安装本版。
2. 保持 FLClash 当前前置固定；网络设置读取当前链路，确认节点选择正确。
3. 点击“验证前置连接”，不要手工猜选三个地址。
4. 将完整结果文字反馈。预期这次进入协议测试；只有唯一候选实际通过才填入。前置回显出口和连接入口可能不同，预期 ISP 出口不能改变。

此修复不代表已完成真实节点的协议验收。仍是预发布版，支持范围沿用 0.5.30 说明。

兜底：独立测试不设置 PF、路由或系统代理，卡住先取消。若之后正式防护测试影响网络，使用安装包或应用内恢复工具，优先正常恢复，模式 3 仅最后兜底。
