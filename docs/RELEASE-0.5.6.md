# 0.5.6 测试版：出口复核与诊断

版本 0.5.6+33，macOS 14+，Apple Silicon / Intel。未获 Apple 公证；Intel 尚需真机验收。本版不改变代理、TUN、DNS 或 PF 允许路径。

## 改进

- 任一检测服务返回不同于预期的公网 IP，立即结束 Claude，不以重试掩盖冲突。
- 检测暂不可用或结果过期时，保持 PF 和本地安全核验，显示黄色复核提示。至少间隔 2 秒复检，连续 3 轮失败或距离最后有效样本 45 秒即停止，取先达到者。
- 正确样本在完成后 10 秒内可用；移除回调排队 3 秒即停机的独立门槛。样本过期不会刷新总时限。一个服务正常、另一个不可用且无冲突时可继续。
- 日志新增逐服务 IP、curl 错误码、耗时、完成时间、回调延迟、证据年龄、重试次数和具体决策。不把检测失败认定为已泄漏。
- 顶部大字单行显示「已阻断数据包 N 次」，删除下方说明；悬停仍说明整机范围及最后一次会话含义。并非危险请求或 Claude 专属计数。

## 手动验收与反馈

1. 记录网络设置。旧版先「恢复并退出」，通过 DMG 中移除工具卸载，再双击安装新版；卸载会清空配置。不要只替换 UI。
2. 用户自行准备代理/TUN，点击「仅验证防护」。应进入 ARMED；分别访问 https://api.ipify.org/ 和 https://ipv4.webshare.io/，核对预期出口。
3. 正常关闭防护后安全启动 Claude，重复原有开发工作至少 30 分钟，包括此前的 CPU 任务。无需人为占满 CPU 或断开网络。顶部阻断计数应为单行大字。
4. 若出现黄色出口复核，记录时间、持续时间及是否恢复绿色。若退出，导出反馈，提交完整 `periodicEgress`、提示原文、事件时间和当时是否仍能浏览网页。不要仅凭超时判断泄漏。
5. 点击「关闭防护」，应退出 Claude 后恢复 OFF；确认网页正常。离线测试已覆盖不匹配立即停止、短暂失败恢复、3 轮/45 秒截止和旧样本不能续期；不用人为切换出口来复现这些分支。

这次旧报告没有逐服务错误证据，不能倒推其退出必然是误判。新版用具体证据区分后续事件。合成测试不能代替本机长时间使用验收。

## 兜底恢复（每轮测试保留）

安装器 → 恢复工具 → `恢复网络.command`：先选 **2** 清除本工具限制，仍断网选 **3**。核验受阻时阅读风险说明后输入 `UNPROTECT`，可能停用整个 PF、影响其他防火墙，不等于正常 OFF 验收。不要继续使用 Claude；仍断网则重启 Mac 并保留输出。
