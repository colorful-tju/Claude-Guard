# Claude Guard 0.5.1 · 个人测试安装修复

修复 0.5.0 从浏览器下载后，外层安装器已获允许、内部助手却被 macOS 终止（137 / Killed: 9）的问题路径。

## 改动

- 图形安装器明确提示未公证，只有确认信任后才允许处理包内 App 的下载隔离属性。
- 解包后先核验签名，仅清除该副本的 com.apple.quarantine，再次核验签名。不会停用 Gatekeeper、SIP，或操作其他应用。
- 在停止旧助手前执行无特权副作用的启动自检；启动失败保留旧服务。
- 区分“安装失败”和“安装成功但 App 打不开”，避免误导用户反复安装。

## 使用

旧版先「恢复并退出」。下载对应 AppleSilicon-arm64 或 Intel-x86_64 DMG，双击安装器。首次打开外层安装器仍可能被 macOS 拦截；仅在确认下载来源后按系统“隐私与安全性”的提示允许。安装器第二个确认框解释个人测试版的信任操作；不接受可取消。

此补丁不是 Developer ID 签名或 Apple 公证的替代品，不承诺所有系统安全策略均放行。企业设备若有额外限制，应联系管理员，不关闭系统防护。Intel 仅完成交叉编译和静态检查，尚无 Intel 真机验收。

两种包均要求 macOS 14+。首次使用仍须按验证手册完成网络与 PF 验收。

## 恢复兜底

从 App 或 DMG 安装器进入「恢复工具」，运行恢复网络.command，先选2，仍断网才选3（全局停用PF）。保留错误输出，不删除未知恢复事务。
