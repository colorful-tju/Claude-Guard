# 0.5.29 测试版（build 57）：修复 UDP 防护规则预检查

修复「UDP dry parse changed protection rules」：macOS PF 会将 DHCP 续租的目标地址集合展开为两条规则，旧版按原始行数比较而误拒绝。新版明确生成广播与已确认私网 DHCP 服务器的独立规则。

预检查改为逐条严格比较 PF 规范化结果，仅处理数值端口显示中的等号，不忽略地址、接口、方向、协议、端口、顺序、标签或 state 约束。缺失、额外规则及同数量内容变化均拒绝。未增加任何网络放行目的地；全局 UDP 拒绝和负向探针/命中计数、恢复机制保持不变。失败提示包含预计/实际条数和首个差异位置，并明确尚未加载防护。

新增真实 macOS `pfctl -n` 只解析测试和规则变异回归，覆盖 DHCP 不同形式及危险变更。开发测试不加载 PF、不切换网络。Intel 仅交叉构建/静态校验；真实防护效果仍需用户手动验收。

验收：完整防护 OFF → 恢复临时 IPv6 租约 → 开启 UDP 防护 → 确认 ARMED 和两个 UDP 负向探针计数 → 浏览 HTTPS → 关闭防护回到 OFF → 导出反馈。仅 UDP 防护不管理 Claude，不保证 TCP 出口。

兜底：关闭防护 → 恢复工具选 2（自身规则）→ 仍断网选 3（全局 PF）→ 必要时重启。保留反馈，不删除事务文件。按 DMG 说明恢复并退出旧版、卸载后安装，先记录设置。
