## 一次诊断操作

1. 关闭防护并退出旧 App，按 DMG 说明安装本地诊断包。
2. 保持 FLClash 当前节点和模式，读取当前链路。
3. 点击“验证前置连接”并等待结束，展开“前置验证记录”。
4. 导出反馈报告（工具栏分享按钮）到桌面 `ClaudeGuard反馈.json`，告诉我“已导出”。也可直接复制记录文字。
5. 不要猜选地址，也先不要启动 Claude 防护。

兜底：独立测试不修改 PF/路由，卡住可取消。若此前正式防护仍影响网络，使用内置恢复工具，优先正常恢复，模式 3 仅最后兜底。
