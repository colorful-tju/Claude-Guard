# 0.5.2 DMG 交付：完整手动验收与反馈

本轮修正手动关闭取消竞态、独立 IPv6 租约，并内置恢复资源，保留三色横幅、软件声明、空白首次配置与通用核心登记。未自动切换任何代理、网络、PF 或 IPv6。保留 DMG 与本文，测试期间不要同时更新组件。

## A. DMG 与 UI（不启用防护）

1. 在旧版中点击“关闭防护”，确认 OFF、Claude/Code 全部退出，临时 IPv6 已恢复。菜单栏“恢复并退出”。
2. 打开 `Claude-Guard-0.5.6-macOS-AppleSilicon-arm64.dmg`，应看到安装器、「移除 Claude Guard.app」与安装顺序说明。已有旧版先记下节点和自定义核心信息，在菜单栏恢复并退出后卸载，再安装；卸载会清空配置。首次安装直接双击安装器即可，无需拖入应用程序，按图形提示选择默认代理或其他兼容核心，并完成管理员授权。本次会匹配 UI 与助手版本，不能只替换 UI。
3. 在成功提示中选择「打开 Claude Guard」。首次使用或已完整卸载的账户应显示引导，网关和预期出口为空，端口 0 表示未填写。正常升级应保留个人配置；更早开发版偏好不会导入，已有恢复资产不会被清除。
4. 端点确认为清晰按钮，确认后变绿，重新检测/修改后需重新确认。恢复工具可打开手册、命令与移除工具。总览仅保留“网络设置”，没有重复端点按钮。未验证为黄；IPv6 默认路由或失败提示为红；只有 ARMED 且 verified 才能为绿。故障消息左对齐，主窗口最小 1100×660，无主页面滚动需求。
5. 软件声明中核对作者 colorful / colorful-tju、版本、源码可见限制；阅读许可、说明、第三方说明均应打开本地文档。
6. 网络设置点问号。点击“检测并填入出口 IP”，两个服务一致后自动修改预期出口，不改网关/端口。检测结果超过 120 秒、失败或已失效时不可使用。
7. 填自己的设置，退出后重开应记住。端点确认、防护状态不自动恢复。主窗口关闭后菜单栏仍在，正常退出应执行恢复。

记录：版本、UI 是否完整显示、初始字段是否空白、帮助与文档是否打开、重开后哪些字段保留。不要把账户凭据发给作者。

另检查：Finder、Dock 和应用信息中应出现新蓝绿色盾牌图标；打开 DMG 不应自动运行安装器、申请管理员授权或更改网络。点击取消不应改变已安装版本。

## B. 原有网络回归（由你手动切换）

1. 按你原来已通过的方式手动准备兼容代理与 TUN。不要改变为未知的新客户端来同时测试多个变量。
2. Claude/Code 退出。核对网关/端口、预期公网 IPv4。重新检测配置，核对候选与指纹，再点击「确认代理端点」。若提示 IPv6 默认路由，先临时关闭；无默认路由无需盲目改动。
3. 先访问 `https://api.ipify.org/` 和 `https://ipv4.webshare.io/`，记录是否均为自己的预期出口。
4. 点击“仅验证防护”，记下时间。等待明确 ARMED；若拒绝，不反复点击，记录原始原因并导出反馈。
5. 在 ARMED 保持至少两分钟，访问上述两个 URL 和普通网页。预期为绿色持续监控，正常网络可用。此阶段不运行 Claude。
6. 点“关闭防护”，预期 OFF、正常网页可用、临时 IPv6 保持当前选择。若状态不符，使用末尾兜底。
7. 重新准备后“安全启动 Claude”：进行普通对话、导出 Markdown、运行常用 Claude Code 指令/子代理。保持五分钟，确认没有异常误停。不要以“对话还能继续”单独认定 PF 有效。
8. 保持 Claude 运行，主动点击关闭防护，确认应用自动结束、PF 清理且无异常弹窗；IPv6 不变化。随后再次仅验证并关闭，应保持 IPv6；最后菜单栏「恢复并退出」应还原原值。导出反馈并记录结束时间。

本系列移除了 GUI 品牌检查，但核心签名、唯一核心、实际网关连接、TUN 归属、PF、探针和最终快照验证都保留。换成其他客户端应单独做同一验收；不支持的配置应明确拒绝，不应因为出口匹配就变绿。

## C. 采集反馈

可用应用的「导出反馈」保存结果；需要完整状态时，在普通用户终端执行：

```bash
'/Applications/ClaudeSafeLauncher.app/Contents/Resources/guardctl' status
```

同时使用应用“导出反馈”。如出现异常，再按现有采集脚本的说明采集；不要公开上传未经检查的原始报告。反馈格式：

```text
版本：0.5.2+28
核心/配置类型（不含凭据）：
点击验证 / ARMED / 停止的本地时间：
两个 IP 服务是否匹配（是/否，无需公开真实 IP）：
检测并填入是否只改变出口字段：
横幅颜色 / 提示是否正确：
Claude 对话、导出、Code 操作：
OFF 后 IPv6 保持 / 退出后原 IPv6 恢复：
错误原文及脱敏报告文件：
是否使用兜底，使用哪一层：
```

## 每次验证的兜底（离线可用）

在 App 点击「恢复工具」打开文件夹与手册。App 无法打开时，双击 DMG 的安装器选择「恢复工具」（不需要安装）。进入恢复文件夹，双击「恢复网络.command」：选 2 清除本工具阻断，仍断网才选 3（全局停用 PF）。以下命令是同一恢复功能的终端备选。

先点击关闭防护。无响应或断网：

```bash
/bin/bash ./scripts/emergency-recover.sh --force-own
```

停止助手、清除本工具 filter；保留事务/token/state，不代表完整 OFF。仍断网才运行：

```bash
/bin/bash ./scripts/emergency-recover.sh --last-resort
```

这会全局禁用 PF，可能影响其他防火墙。临时 IPv6 尚未恢复时，在助手停止且本工具 filter 清除后运行：

```bash
sudo '/Library/PrivilegedHelperTools/local.claudesafelauncher.guard' --restore-ipv6
```

恢复包脚本同样可用，不依赖 App。若脚本不可用且网络完全断开，可明确选择在终端执行 `sudo launchctl bootout system/local.claudesafelauncher.guard` 后 `sudo pfctl -d`（同样全局影响）。仍无效则重启，保留日志，不清理未知事务文件。恢复后先分析，不立即重试安全启动。

## 完整卸载与首次启动回归（0.5.2）

1. 在当前 App 菜单栏选择「恢复并退出」。
2. 打开 **0.5.2 DMG** 的安装器 →「恢复工具」→「移除 Claude Guard.app」。无需先安装新版；不要使用旧版内置移除程序。
3. 授权后应提示 App、助手及当前用户节点/引导设置已移除并核验。任何错误都不算卸载成功。
4. 可在终端检查 `defaults read local.claudesafelauncher.app publicOnboardingV1` 和 `defaults -currentHost read local.claudesafelauncher.app publicOnboardingV1`，两条都应提示不存在。
5. 重新打开同一 DMG 安装器安装，首次打开应进入引导且无旧节点；不需要开启防护即可验收。记录是否弹出引导、字段是否空白、卸载提示及操作时间。

兜底：恢复受阻时不要继续卸载，使用该 DMG 安装器「恢复工具」中的恢复网络.command，先选 2，仍断网才选 3（全局停用 PF）；保留输出反馈。

## 0.5.2 双架构与一键出口检测

按芯片选择 AppleSilicon-arm64 或 Intel-x86_64 DMG；不匹配的安装包会拒绝安装。Intel 为交叉构建，须单独完成真机验收。网络设置点击「检测并填入出口 IP」后，两个服务一致才自动填写预期出口，网关和端口不变。检测失败、不一致或期间修改配置时应不覆盖旧值。该检测不启动 PF，也不证明防护已生效。

## 0.5.2 浏览器下载安装验收

1. 旧 App 菜单栏「恢复并退出」，保持当前代理不变。
2. 从 GitHub 用浏览器下载对应芯片 0.5.2 DMG，不使用本地未下载副本替代本项测试。
3. 外层安装器若被拦截，确认来源后按 macOS「隐私与安全性」允许打开。阅读个人测试版信任说明；确认后才授权安装。
4. 应不再在 guard-daemon --assert-off 阶段报137。若新助手启动失败，应提示旧助手尚未停止；不要重复安装，保存完整错误和时间。
5. 安装成功后打开 App，确认0.5.2。先只检查界面和配置，本项不要求开启PF。
6. 反馈：芯片、macOS版本、下载方式、安装器允许次数、是否出现内部App第二次拦截、完整提示与时间。

兜底：App或DMG安装器「恢复工具」→恢复网络.command，先2，仍断网才3（全局停用PF）；保留输出。


## 0.5.5 增量验收：高负载与阻断计数

先完成本手册的基线和恢复检查，再按 [0.5.5 发布说明](RELEASE-0.5.5.md) 的步骤验证。重点记录负载任务开始、黄色提醒、自动停止和手动 OFF 的时间，导出反馈中的 `heartbeatDiagnostic`、`uiHeartbeat`、`blockedPackets` 及 `blockedPacketsAt`。计数包含整机流量，不应以“0”或“大于 0”单独判定安全或泄漏。

兜底：安装器 → 恢复工具 → 恢复网络.command，先选 2；仍断网选 3。核验受阻时阅读说明后确认 UNPROTECT（可能影响其他 PF 防火墙）。不要继续使用 Claude；仍断网请重启并保留输出。
