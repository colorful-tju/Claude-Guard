# 0.5.20 测试版：从 FLClash 列表选择配置

版本 0.5.20+47，macOS 14+；提供 Apple Silicon 和 Intel 安装包。临时签名、未获 Apple 公证；Intel 未真机验收。

## 新增

- 网络设置新增 **读取 FLClash 配置**：按订阅名称列出本机保存的 YAML，附文件名及修改时间，无需查找隐藏目录。
- 选中订阅后点 **选择并登记**，沿用已有 OFF 登记和端点确认流程；保留手动选文件入口。
- 生成的 `config.yaml` 单独标注“可能不是当前订阅”；名称数据库暂不可读时按文件名显示，并支持刷新。
- 配置列表使用只读查询，不查询订阅地址或凭据，不修改 YAML 或订阅数据、不切换节点，不自动选择或登记任何项目。

支持标准 macOS FLClash 数据目录。不同版本数据库结构或自定义安装位置可能需要手动选文件；列表不是核心运行态证明，安全启动仍检查 Core 身份、实际网关连接、TUN、PF、负向探针和出口。多节点、非 HTTP 等限制保持不变。

## 更新与验证

1. 按 DMG 说明先恢复并退出旧版、保存设置，再移除旧版并安装对应芯片的新包。
2. 在 OFF 状态打开 **网络设置 → 读取 FLClash 配置**，选择你当前使用的单节点 HTTP 订阅，点击 **选择并登记**。
3. 核对候选网关和端口，填写预期出口并重新确认端点；先仅验证防护，通过后再安全启动 Claude。
4. 取消选择应保持原登记。列表没有新导入的配置时可刷新；仍有问题用手动选文件，并导出反馈。

本轮离线测试与 DMG 核验不代替用户设备上的真实 PF/代理验收。

## 兜底恢复

安装器 → 恢复工具 → `恢复网络.command`，先选 **2**，仍断网选 **3**（可能停用整个 PF，影响其他防火墙）。受阻按说明确认 `UNPROTECT`；仍无法联网请重启并保留输出。
