# 0.5.15 测试版：出口检测不可用时仅提醒

版本 0.5.15+42，macOS 14+；Apple Silicon / Intel。临时签名，未获 Apple 公证，Intel 尚未真机验收。

## 按用户要求调整策略

- 首次启动前仍必须成功核验预期出口。
- 运行中检测到任一服务返回不同公网 IPv4：立即执行结束 Claude/Code 与恢复流程，并弹窗。
- 超时、TLS/HTTP 错误、没有有效 IP 或结果过旧：不关闭 Claude，保持 PF 与所有本地前提核验，5 分钟后重测。
- 第二次仍无法核验：弹窗明确「Claude 未关闭，PF 仍运行，当前出口尚未确认」。同一故障只弹一次，之后每 5 分钟继续检测。
- 成功核验后自动清除待核验状态，恢复约 15 秒检测频率。后续新故障可再次提醒。
- 不再因运行中出口结果缺失而执行原有的 45 秒或三次失败停止；不修改心跳、PF、TUN、网关、进程身份与恢复规则。无效内部证据、取消或时钟异常仍按原安全原则停止。

这是一项明确的安全与可用性取舍：检测服务不可用期间，程序不能证明公网出口仍为预期 IP。界面保持黄色待核验提示，不把旧结果当作当前已核验结果。没有承诺服务商出口不变。

## 离线验收

模拟时钟覆盖超过五分钟等待、三轮及更多无结果仍保持 PF、第二次警告、同一故障警告去重、恢复后清除、错误出口仍立即停止；UI 测试检查警告独立于停止事件，不能误称已关闭 Claude。首次启动探针和 PF 异常停止沿用原回归。

## 手动验证

1. 保存配置，正常关闭防护确认 OFF，按安装包说明卸载旧版再安装；卸载会清空设置。
2. 手动准备原代理/TUN和 IPv6 设置。先「仅验证防护」，确认 ARMED 与预期出口；正常退出后再安全启动 Claude。
3. 正常使用至少 30 分钟，包含原来的模拟器调试场景。不要为测试直接断网或改变路由，这些仍可能触发其他安全条件。
4. 如果自然发生出口检测不可用，应保持 Claude 和 PF，黄色提示待核验。约 5 分钟后的重测仍失败才弹提醒；之后不应每秒反复弹窗。检测恢复后提示消失。没有遇到检测失败则本轮无法验证提醒路径，不等于提醒测试已通过。
5. 导出反馈并附开始、异常、弹窗和恢复时间，记录 Claude 是否继续工作。正常关闭防护后确认 OFF 和网页可用。

## 兜底恢复

安装器 → 恢复工具 → `恢复网络.command`，先选 **2**，仍断网选 **3**。核验受阻时阅读说明后输入 `UNPROTECT`；选项 3 可能停用整个 PF 并影响其他防火墙，不等于正常 OFF 验收。不要继续使用 Claude；仍断网则重启并保留输出。
