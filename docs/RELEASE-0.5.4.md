# 0.5.4 测试版：socket 采集竞态

本次反馈显示：ARMED 约 25 分钟后，代理 Core 的 socket 清单读取失败，启动器主动停止 Claude。首次终止核验尚有进程，保留防护并进入恢复受阻；自动重试随后完成 OFF。不是网卡变动报错，没有证据证明 IP 泄漏或启动器崩溃。

旧实现对任意 FD 明细读取失败直接终止整个采集。socket 在清单枚举和明细读取之间关闭可触发该行为；旧日志缺少 errno，因此无法确认本次具体系统错误。新实现以同一进程身份为前提，最多三次完整重采样，间隔 25ms；不得合并部分结果或使用旧快照，持续失败仍停止。最终失败新增 PID、尝试次数和 errno。恢复成功后修正事件中陈旧的“退出未确认”。

## 手动验证

1. 先记下节点与自定义核心设置，旧版菜单栏「恢复并退出」，在 DMG 顶层卸载旧版，再安装 0.5.4+31；卸载清空设置，安装后需重新填写。
2. 用户自行准备原代理/TUN；先执行仅验证防护，确认 ARMED 和预期出口，再正常 OFF。
3. 安全启动 Claude，连续使用 45–60 分钟，覆盖 Claude Code 子任务、网页访问和文件导出；不主动切换网络。
4. 正常关闭防护后导出反馈。若中途停止，记录时间并立即导出，新日志中的 PID/errno/attempts 可进一步区分 FD 竞态、权限或容量问题。

socket 修复版用户反馈使用稳定。本轮增加 DMG 顶层卸载工具和安装顺序说明；打包不运行真实卸载或安装，不改动当前网络。新增安装流程仍需用户真机验收。

兜底：安装器 → 恢复工具 → 恢复网络.command，先选 2，仍断网选 3；核验受阻时阅读提示后确认 UNPROTECT（会停用整个 PF，影响其他防火墙）。不要继续使用 Claude；仍断网请重启并保留输出。
